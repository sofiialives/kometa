## 1. Скорость загрузки

**Видео пересжато без потери качества.** Исходник шёл с битрейтом 16 Мбит/с — избыточно для 3-секундного ролика. Пересобрали в H.264 CRF 27 плюс версия WebM VP9 для Chrome и Firefox. Разница в 13 раз при том же изображении.

**Три версии под разные условия.** Десктоп получает `hero.mp4` (432 КБ), мобильные — `hero-mobile.mp4` (188 КБ, ширина 1280). Браузер сам выбирает WebM, если умеет его читать.

**Видео не грузится, пока не нужно.** Атрибут `preload="none"` и подгрузка через JS: сначала показывается постер в WebP (56 КБ), видео начинает качаться следом. Пользователь видит картинку мгновенно.

**Критический CSS встроен в HTML.** Стили первого экрана идут прямо в документе, остальной файл подключается без блокировки рендера. Страница отрисовывается, не дожидаясь загрузки CSS.

**Шрифты предзагружены** через `rel="preload"` с `font-display: swap` — текст виден сразу системным шрифтом и подменяется, когда придёт Nekst.

**Изображения в WebP** с автоматическим откатом на PNG через `image-set()` — экономия до 95% (звёздный фон: 1.2 МБ → 50 КБ).

**Третья секция не рендерится, пока не видна** — свойство `content-visibility: auto` с зарезервированной высотой.

## 2. Поведение на слабом интернете

Модуль `media-loader.js` определяет качество соединения через Network Information API.

**Если 2G или включена экономия трафика** — видео не загружается вообще. Показывается статичный постер, пользователь видит осмысленную подпись «Экономия трафика — видео отключено» и сразу листает дальше.

**Прогресс-бар показывает реальную загрузку** — читается через `video.buffered`, а не имитируется таймером.

**Сторож на 9 секунд.** Если видео не догрузилось — переходим в статичный режим и отпускаем пользователя. Никто не залипнет на бесконечном лоадере.

**Обработка ошибок кодеков.** Если браузер не умеет ни MP4, ни WebM, сайт молча переключается на статичный кадр.

## 3. SEO

**Мета-теги:** title до 70 символов, description 178 символов, canonical, hreflang, robots с директивами `max-image-preview:large` для расширенных сниппетов.

**Open Graph:** обложка 1200×630 в JPEG — правильный формат для превью в мессенджерах.

> Частая ошибка: ставить SVG в `og:image`. Facebook, Telegram и Twitter его не отображают — превью будет пустым. На сайте hochuplachu.com сейчас именно так: `og:image: /images/logo.svg`. Ссылка расшарится без картинки.

**JSON-LD разметка** из четырёх связанных узлов: Organization, WebSite, WebPage, ItemList с перечнем услуг. Поисковики понимают, что за компания, чем занимается и какие направления предлагает.

**robots.txt** с `Clean-param` для Яндекса — UTM-метки не плодят дубли страниц.

**sitemap.xml** с расширением image — обложка индексируется отдельно.

## 4. Семантика и доступность

**Один H1 на страницу** — обязательное правило. Раньше на сайте не было ни одного заголовка первого уровня: поисковик не понимал, о чём страница.

**Landmark-теги:** `header`, `nav`, `main`, `section` — скринридер и робот видят структуру документа.

**Skip-link** — первая ссылка на странице позволяет перепрыгнуть навигацию с клавиатуры.

**Все изображения с alt**, декоративные помечены `aria-hidden`, у всех заданы `width` и `height` — макет не прыгает при загрузке (метрика CLS).

**Прогресс-бар с ролью** `progressbar` и живым `aria-valuenow`.

**Работает без JavaScript** — блок `noscript` прячет лоадер и показывает контент.

**Уважает системные настройки:** при включённом «уменьшить движение» все анимации отключаются.

## 5. Кроссбраузерность

Префиксы `-webkit-` для `mask`, `backdrop-filter`, `image-set`. Проверки через `@supports`: если браузер не умеет `mask-composite` — декоративные узоры скрываются, вёрстка не ломается. Если нет `backdrop-filter` — стеклянные панели заменяются плотным фоном.

Поддержка: Chrome, Firefox, Safari, Edge актуальных версий, включая Safari 15+.

---

## 6. Безопасность и кэширование

Заголовки `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy` — в трёх форматах: `.htaccess` для Apache, `_headers` для Netlify, `vercel.json` для Vercel.

Статика кэшируется на год как `immutable`, HTML — с обязательной проверкой актуальности.

---

## 7. Страница 404

Не статическая заглушка, а живая сцена: звёздное небо на canvas с тремя слоями параллакса, пролетающие кометы, планета вместо нуля с вращающимся кольцом, реакция на движение мыши.

Оптимизирована: рендер останавливается при переключении вкладки, `devicePixelRatio` ограничен двойкой, при `prefers-reduced-motion` рисуется один статичный кадр.
