Сюда положите видео вращения планеты:

  hero.mp4    — обязательно
  hero.webm   — опционально, грузится первым если есть

Требования к файлу:
  - без звука
  - частые ключевые кадры, иначе перемотка по скроллу будет дёргаться
  - длительность 4-8 секунд

Перекодировать под скролл:
  ffmpeg -i source.mp4 -an -c:v libx264 -crf 22 -g 2 -pix_fmt yuv420p hero.mp4
  ffmpeg -i source.mp4 -an -c:v libvpx-vp9 -crf 32 -b:v 0 -g 2 hero.webm

Параметр -g 2 ставит ключевой кадр каждые 2 кадра — это главное для плавной перемотки.
